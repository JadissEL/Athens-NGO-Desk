# Greece NGO Desk — design brief (Stitch)

**Product:** Greece NGO Desk — Greece-wide civic signposting (jobseekers, funders, donors, service seekers). Not a crisis hotline. Athens is a filter, not the product name.

**Tone:** Premium Aegean civic SaaS — trustworthy, editorial, dense but calm (Linear / Stripe / Notion on desktop).

## Tokens

- Teal accent `#0f7c7c`, hover `#0b5e5e`, deep ink `#0a2e2e`
- Terracotta sun `#d97736` for urgency / application accents
- Surfaces: warm white cards, mesh background `#e9eff8`
- Bento pastels: mint, sand, sky, coral, lavender (card caps)
- Radius: cards 24–32px; pills full round
- Type: Playfair Display hero H1; Manrope / Plus Jakarta UI

## Shell (desktop ≥1024px)

- 92px dark teal icon sidebar
- Frosted glass top bar, grouped nav, Ctrl+K, primary Apply by email
- NO bottom tab bar on desktop

## Patterns

- Search dock card (hero + workbenches)
- Master–detail: scrollable list + sticky right panel (jobs, registry)
- Job cards: horizontal row layout in list, not 3-column grid
- NGO cards: score pill on cap, initials avatar
- Application panel: terracotta-to-teal top stripe

## Pages

Home, Openings, Registry, Org profile, Media, Apply, Scores, Guides (Life, Found, Fund), Audiences, Legal.

Mobile: intentional adaptation — bottom dock, drawer detail, not shrunk desktop.
